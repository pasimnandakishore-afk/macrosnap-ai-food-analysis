📸 MacroSnap

AI-Powered Food & Nutrition Analyzer

MacroSnap is a web application designed to analyze food images and provide estimated nutritional information such as calories, protein, carbohydrates, and fat.

🚀 Features

- 📷 Upload a food image
- 🖼️ Preview the selected image
- 🤖 AI food analysis interface
- 🔥 Calorie estimation
- 💪 Protein estimation
- 🍚 Carbohydrate estimation
- 🥑 Fat estimation
- 📱 Mobile-friendly responsive design
- 💻 Works on desktop and mobile browsers

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

📁 Project Structure

MacroSnap/

▶️ How to Run

1. Download or clone this repository.
2. Open the MacroSnap folder.
3. Open "index.html" in a web browser.
4. Select a food image.
5. Click Analyze Food.
6. View the estimated nutrition result.

🤖 AI Functionality

The current version contains a demonstration analysis system.

The project can later be connected to a real AI Vision API to identify food from images and provide more accurate nutritional information.
